# 리더주 반전 스크리너 & 백테스트 (미국 주식)

하락장에서 아무 주식이나 싸다고 사는 게 아니라, **강했던 주식 중 가장 먼저 하락을 멈춘 주식**을 찾는 전략입니다.

| 단계 | 조건 (기본값) |
|---|---|
| ① 리더주 | 1년 내 고점 시점의 6개월 수익률이 유니버스 상위 20% 이내 |
| ② 큰 조정 | 고점 대비 -30% ~ -60% |
| ③ 다이버전스 | 종목이 저점을 찍은 **뒤에** 시장 지수(SPY/QQQ)는 더 낮은 저점을 만들었는데, 종목은 저점을 지킴 |
| ④ 돌파 | 저점 이후 횡보구간 고점(피벗)을 **50일 평균 1.5배 이상 거래량**으로 종가 돌파, 지수는 20일선 위 |
| 매수 | 돌파 다음 날 시가 |
| 매도 | -8% 손절 / +15% 도달 후 본전 손절 / 50일선 종가 이탈 / 최대 1년 보유 |
| 유동성 | 주가 $10 이상, 50일 평균 거래대금 $20M 이상 |

모든 값은 `strategy.py`의 `Params`에서 바꿀 수 있습니다.

## 설치

```bash
pip install -r stock_screener/requirements.txt
```

## 스크리너

```bash
python -m stock_screener.screener                  # 오늘 기준
python -m stock_screener.screener --market QQQ     # 나스닥100과 비교
python -m stock_screener.screener --as-of 2022-11-30   # 과거 시점 재현
```

- **[A] 최근 돌파 신호**: ①~④ 모두 충족 (최근 5거래일)
- **[B] 돌파 대기**: ①~③ 충족. `to_pivot` = 피벗까지 남은 상승률. 이 목록을 관심종목에 넣고 돌파를 기다리면 됩니다.
- **[C] 관찰**: ①② 충족, 아직 시장이 더 낮은 저점을 만들지 않아 ③이 미확인

결과 CSV: `stock_screener/output/`

## 백테스트

```bash
python -m stock_screener.backtest                  # 2005년~현재
python -m stock_screener.backtest --compare        # 조건을 하나씩 뺀 버전과 비교
python -m stock_screener.backtest --max-positions 5
```

출력:
1. 트레이드 통계: 승률, 평균 수익/손실, 손익비, 1회 기대값, 청산 사유
2. 하락장 구간별 성과: 2008, 2011, 2015-16, 2018 말, 2020, 2022, 2025
3. 포트폴리오(최대 10종목 균등) vs 지수 단순 보유: CAGR, MDD, 샤프
4. `--compare`: ③ 다이버전스, 지수 필터, ① 리더주 조건을 각각 뺐을 때와 비교 → 각 조건이 실제로 도움이 되는지 확인

처음 실행하면 약 600종목, 20년치를 받느라 몇 분 걸립니다. 받은 데이터는 `data_cache/`에 12시간 동안 캐시됩니다.

GitHub Actions(`Stock screener & backtest` 워크플로)에서도 돌아가며, 결과는 실행 페이지의 `stock-results` 아티팩트로 받을 수 있습니다.

## 결과를 볼 때 꼭 알아야 할 한계

- **생존 편향**: 유니버스가 *현재* S&P 500 + Nasdaq-100 구성 종목입니다. 과거에 상장폐지되거나 지수에서 빠진 종목이 없어서, 특히 2008년 같은 오래된 구간일수록 결과가 실제보다 좋게 나옵니다.
- **체결 가정**: 다음 날 시가 매수, 편도 비용 0.1%. 갭 하락 시 손절은 시가에 체결된 것으로 처리합니다.
- **과최적화 주의**: `--compare`로 파라미터를 이것저것 바꿔 가장 좋은 숫자를 고르면 미래에는 그만큼 안 나옵니다. 조건 하나를 바꿨을 때 결과가 크게 흔들린다면 그 전략은 믿기 어렵습니다.
- 투자 판단의 참고 도구일 뿐, 매수·매도 추천이 아닙니다.
